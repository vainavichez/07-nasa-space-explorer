# Project 7: NASA API - Space Explorer App
NASA releases a new "Astronomy Picture of the Day" (APOD) every day—spotlighting breathtaking images of galaxies, stars, planets, and more.

This interactive web app fetches and displays these photos using [NASA's APOD API](https://api.nasa.gov/#apod). Choose a date range and click **Get Space Images** to view the images, titles, and dates.

You'll get to use your skills to build something that's actually connected to real-world data from one of the most iconic organizations in the world.

## Starter Files
- The provided files include a NASA logo, date inputs, a button, a placeholder for your gallery, and basic layout and styling.
- It also includes built-in logic (in `dateRange.js`) to handle the valid APOD date range—from June 16, 1995 to today. No need to modify it.
- The APOD request currently uses NASA's public `DEMO_KEY` in `script.js`, which has a low request limit. For regular use, replace it with a personal key from [api.nasa.gov](https://api.nasa.gov/).
